# Assessment delivery artifacts

`walkthrough.mp4` (gitignored; share it separately) is a 2 min 35 s captioned, silent recording of the app in live AI mode (Qwen 3.5 via local Ollama), recorded 2026-11-19: image → Instagram Reel with a brand colour and logo, the caption package, a new version for YouTube (thumbnail with a new hook), Recent creatives, video → TikTok (reframed, audio kept), product URL → YouTube thumbnail, an unsafe URL refused, an expired result (its media deleted by the retention purge), and a link opened in another browser. AI and render waits are fast-forwarded at 8× and the caption says so each time. Captions sit in a band below the page, so they never cover the app; everything else is real time. It uses only the synthetic sample image, a clip made from it, and a public sample photo. The earlier recording is kept as `walkthrough-2026-11-17.mp4`.

Public deployment requires a writable hosting target and explicit spending authorization. A prepared HTTPS/reviewer-access proxy is in `infrastructure/docker-compose.public.yml`.
