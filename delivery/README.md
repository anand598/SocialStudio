# Assessment delivery artifacts

`walkthrough.mp4` (gitignored) is a captioned, silent recording of the live app: image → Instagram Reel, video → TikTok, product URL → YouTube thumbnail, refresh restore, unsafe-input rejection, and per-browser access control. AI waits are shown in real time. Runtime uploads and private user results are excluded from repository commits. The walkthrough must use the synthetic sample asset and must not show personal browser tabs or credentials.

Public deployment requires a writable hosting target and explicit spending authorization. A prepared HTTPS/reviewer-access proxy is in `infrastructure/docker-compose.public.yml`.
